# v0.1.54

修复历史进度续播时短暂播放片头声音，以及 Android 分段读取连接被误关闭的问题，并合入本地界面细节改进。

- 续播和跳转后的音视频过滤使用固定的目标时间门槛。视频先进入播放状态时，晚到的片头音频仍会被丢弃；向后跳转和重新从头播放会更新门槛。
- Android 为当前连接和两条保留连接分别管理代理读取编号。音视频交替读取不会互相关闭连接，淘汰连接后复用编号，继续清理废弃读者并保持并发上限。
- 调整桌面顶栏、服务器切换、分集列表、片库统计和播放设置布局；改进手机连接页的密码显示、错误提示和筛选状态。

验证包含真实 HTTP 连接取消回归、Android CoreInput 测试、代理连接隔离/容量回归，以及原生续播、向后跳转和从头重播测试。旧 Android 读取实现已在合成 HTTP 场景中复现 `EIO (-5)`。这些测试不能代替用户实际片源、物理音频和各平台硬件验收。

本地检查：依赖获取、格式化和静态分析通过；Flutter 全量测试 1586 项通过、2 项跳过；Android CoreInput 14 项通过；原生 CTest 11 项通过。Android arm64 SDK 的锁定源码、补丁与库文件哈希校验通过。

本地手机验证包使用独立的 `.validation` 包名和本地测试签名，以 release 模式编译，与正式版并存。正式签名发布包由标签工作流构建、校验和发布。
