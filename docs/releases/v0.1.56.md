# v0.1.56

本次更新调整播放缓存调度、音轨记忆和 Android 音频输出，并合入主分支的浏览界面与电视选集改进。

- 缓存继续读取用户配置的磁盘预算（包括 2 GiB），内存缓冲单独限额；复用读取缓冲，减少重复磁盘读取、校验和索引开销。
- 调整后台预读与当前播放请求的调度，避免远处播放请求被中间未缓存区域阻塞；修正并发写入时已校验缓存范围被清空的路径。
- MP4 索引只展开选定音视频轨道，调整首次索引构建的协作执行预算。
- 完善上次音轨选择的恢复，调整 Android 音频写入节奏及输入缓冲复用。
- 修正慢响应的有效响应头到达、正文尚未到达时，起播逻辑可能提前触发换源的竞态。
- 精简浏览页重复状态信息，电视剧集列表定位到继续播放的集数。

## 已知问题与验证范围

Android TV 实机仍有卡顿、缓存条断裂或闪烁的反馈，本版本未完成这些问题的修复验收。字节缓存范围不能等同于连续可播放时长；已有磁盘缓存也不能保证硬件解码器成功创建。

此前一次 HEVC 硬解创建失败在重启盒子后恢复，尚未证明根因已解决。自动测试和本地构建结果不代表实机流畅度、物理音频输出或硬件稳定性通过。发布资产由 tag 工作流构建并执行哈希、签名及原生依赖检查。
