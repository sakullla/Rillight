# v0.1.53

修复 macOS 发布构建在 Xcode 的 Python 环境中导入原生打包脚本失败的问题，保留 v0.1.52 的播放与兼容性修复。

- 延迟求值原生依赖脚本中的类型标注，兼容 Xcode 使用的 Python 3.9，避免 `Path | None` 在导入阶段触发 `TypeError`。
- macOS CI 同时使用配置的 Python 和系统 Python 执行打包回归检查，覆盖 Xcode 构建阶段的解释器差异。

本地 Python 3.9 已复现原始异常；修复后 Python 3.9 和当前 Python 的 macOS 打包单元测试各 18 项通过，播放器辅助脚本导入通过。原生构建辅助测试 8 项及工作流合同测试 4 项通过。实际 macOS 构建、签名和发布包由 CI 验证；这些检查不代表真机音视频或硬件验收。
