# Rillight v0.1.46

改善 Android TV 播放控制和缓存处理，修复硬件解码失败后的恢复流程。

- 切换片源、音轨和字幕时保留遥控器焦点，并恢复对应来源的音轨与字幕记忆。
- 减少缓存目录重复扫描、重复校验和预读对正在播放数据的内存驱逐。
- 调整 Android 视频帧提交时机和音频供给；硬解或画面提交失败时从关键帧重建播放时间线。
- 保留原生杜比隧道的实验实现，默认关闭；正式构建继续使用兼容播放路径。
- 合入桌面播放恢复时保留播放／暂停意图的修复。
- 修复 Android 64 位构建的时间戳类型冲突，同步 macOS 核心接口头文件，并修复 Linux 安装检查中的短暂窗口竞态。

已知问题：Android TV 的 4K HDR 60fps 卡顿、起播慢仍待排查。原生杜比隧道在已测试设备／显示器组合上仍偏绿或紫色，升级系统固件后仍可复现。本版本不宣称修复这些问题。

验证：本地 Flutter 全量测试 1531 项通过、2 项跳过，播放器包测试 9 项通过，Windows 原生测试 11 项通过；Android Kotlin 单元测试、ARM32 profile 构建、静态分析、FFmpeg 补丁与发布契约检查通过。各平台正式包由 tag 工作流构建、审计后发布；上述检查不代表物理音频、HDR 颜色或所有设备性能验收。
