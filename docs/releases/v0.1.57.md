# v0.1.57

本次更新修正 STRM 播放、HLS 跳转和缓存条显示。

- 远程 strm 直接播放媒体地址。本地 strm 指针读取正文里的 http(s) 目标；下载失败时退回原来的转码地址。
- 转码 HLS 已带 StartTimeTicks，核心从 0 打开，进度显示再加上这段起点。
- 直接播放的 HLS/TS 从容器 start_time 扣除画面、音频和内嵌字幕时钟，只在 seek 时加回。外挂字幕仍按自己的时间轴。
- 时间轴或 HLS 时长尚未就绪时不再叠画字节缓存条；短暂缺口保留上一份已知区间。手机端缓冲提示移到进度条下方。

## 已知问题与验证范围

本地只重编并加载核对了 Windows 核心 ABI 与版本字符串。未做实机画面、跳转或物理音频验收。Android、macOS、Linux 包由 tag 工作流从同一份核心源码构建。自动测试不代表实机流畅度、物理音频或硬件稳定性通过。发布资产由 tag 工作流执行哈希、签名及原生依赖检查。
