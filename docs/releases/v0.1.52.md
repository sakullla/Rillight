# v0.1.52

修复切换片源后下载停顿、播放中断并出现 HTTP 5xx 错误的问题。

- 为每个原生媒体读取器增加跨分段请求保留的标识。
- 在本地代理检查请求容量之前释放同一读取器的旧请求，防止残留请求占满名额并触发 503；其他音轨和字幕读取保持独立。
- 增加请求名额耗尽和原生分段标识的回归检查。
- 修正 Android 音频帧 JNI 构造函数的 R8 保留规则与 APK 审计签名，避免发布包缺少原生回调入口。
- 修正 Linux PulseAudio 编码格式访问方式，恢复原生播放器编译兼容性。
- 更新 macOS 打包回归检查，确认不再复制已移除的画质增强模型，并清理旧包残留模型。
- 稳定滚动中海报加载的回归测试：等待实际请求并验证滚动仍在进行，消除固定 20 毫秒等待导致的 CI 偶发失败。

Windows 实际切源复测可持续播放，请求峰值为 2、拒绝次数为 0。原生 CTest 11 项、缓存合同 49 项及真实原生核心与 Dart 传输层的下一集／跳转检查通过。这些结果不代表所有源站网络波动或硬件组合均已验证。

Android 发布审计单元测试 36 项、macOS 打包单元测试 18 项通过；Linux 音频输出头文件使用 WSL Debian 的真实 PulseAudio 开发头文件通过严格 C++17 编译检查。上述平台检查不代表 Android/macOS/Linux 真机播放验收，完整发布包仍由标签工作流构建与审计。

发布前已完成依赖解析、391 个 Dart 文件格式检查和全项目静态分析。Flutter 主测试及播放器包测试首轮 1593 项通过、2 项跳过，另行隔离执行的桌面辅助进程测试 1 项通过；唯一失败的海报异步时序测试修正后，单项及整个组件测试集 126 项复测通过，修改文件静态分析无问题。
