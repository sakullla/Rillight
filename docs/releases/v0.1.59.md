# v0.1.59

本次更新加入 Jellyfin、Plex 支持，并调整播放启动、缓存显示与登录交互。

- 统一接入 Emby、Jellyfin、Plex 的登录、媒体浏览、播放、聚合和私密区域，兼容已有数据；Plex 支持授权、家庭用户与共享服务器。
- 桌面、手机和 TV 登录页可直接切换服务类型，表单同步变化。
- 合入最新浅色主题、桌面返回按钮与 Windows 标题栏调整。
- 播放与缓存合并为一条进度条：优先显示已验证的时间区间，尚无时间映射时以字节比例估算显示。估算不参与 seek 或可播放状态判断。
- 桌面下载保持连续传输，减少重复请求；复用媒体索引，避免下载过程中反复解析不支持的元数据。
- 下一集预读片段在校验内容版本后并入正常缓存，解决切集后下载速度和缓存进度延迟更新；缺少可靠版本标识时按正常网络路径播放。
- 收紧桌面静音按钮与音量滑条间距，保留按钮及滑条的操作区域。
- 桌面续播和网络重连先恢复音量、速度及音轨，再释放播放；Windows PCM 起始采样加入短渐入。
- 修复切换音轨时被中断的连接无法恢复问题。桌面移除前后十秒跳转按钮，保留时间轴和快捷键。
- 减少桌面起播前的重复元数据与协商请求；已知季的剧集加载不再等待季列表。
- STRM 无可用转码回退时保留真实 HTTP 错误，避免统一误报“没有可播放的流”。失效的服务器媒体源仍需服务器端修复。
- 发布前重新下载上传的安装包，核对 SHA256SUMS 后才允许公开 Release。

## 验证范围

HLS 与下载链路使用隔离合成服务检查，覆盖重定向、相对清单地址、分片 Range 请求、密钥与初始化片段、签名参数、跨域凭据隔离、弱网续传及缓存跳转；原生测试覆盖加密 HLS、缺失密钥、损坏填充和暂时不可读。

自动化测试不代表各平台实机流畅度、物理音频或 GPU 稳定性验收，也不构成真实服务器起播耗时的性能测量。安装包由标签工作流构建并执行依赖、哈希及适用的签名检查。
