# 需求：灯川 Rillight 影院界面与登录线路

日期：2026-09-11

## 一屏摘要

- 目标：把「灯川 Rillight」做成影院暗色、海报优先的桌面观影界面；登录后按分栏浏览，能左右翻、「更多」、排序，并能看见切服务器（R1、R3、R9–R11）
- 使用者：自建 Emby、用键盘鼠标看片的桌面用户（R1）
- 范围：重做连接与登录后壳、首页、片库/主题列表、详情、搜索、播放层；多服务器入口必须在登录后可见；播放器独立窗口（R1–R6、R8–R11）
- 关键行为：去掉无用的左侧片库长栏；顶栏能看到当前服务器并切换；分栏有「更多」和左右翻；点进主题/片库/更多页可排序。关掉播放窗口不得退出浏览应用（R8–R11）
- 成功标准：登录后不像后台壳；不靠左侧长栏找片；能从顶栏切服务器；分栏能翻完；主题页能改排序（R3、R9–R11）
- 不做事项：不套官方 Web；不做直播/音乐/相册主导航；不为电视遥控验收；不把片库堆成溢出的 NavigationRail（R7、R10）

## 完整需求

### R1 影院暗色观影界面

行为：在 Windows、macOS 与 Linux 桌面上，灯川 Rillight 的连接、登录后浏览壳、首页、片库、详情、搜索与播放使用同一套影院暗色语言：深色底、大海报、少边框、少系统铬、少同时出现的控件。信息按键鼠密度排列，可点击、可扫过，不是客厅十英尺大磁贴，也不是后台管理表单。界面与安装包可见产品名为「灯川 Rillight」，默认简体中文。不跟随操作系统浅色主题。

适用与失败边界：只验收桌面键鼠图形界面。允许三平台窗框由系统绘制。当前默认 Material 蓝顶栏、NavigationRail 堆标签、无「更多」、看不见左右翻页的截断列表，视为未完成，不是可接受实现。不把浅色系统主题下的可读性作为本需求通过条件。客厅遥控、手机与平板不是本需求验收对象。

验收：

- 登录后首页、片库、详情同一套暗底海报语言，而不是浅色 Material 默认壳
- 产品名「灯川 Rillight」在窗口或登录主表面可见
- 用键盘鼠标能完成进入首页、打开海报、开始播放，无需遥控器

### R2 登录页为重点

行为：未登录或退出后进入登录页。该页与登录后浏览页同等需要重做，不得只美化登录而把片库留成默认壳。登录页展示产品名，选择或添加服务器，选择或添加线路，输入用户名与密码后连接。已保存的服务器与线路可从本页再次选中，不必重填地址。连接失败留在登录页并显示原因。

适用与失败边界：登录页服务于已有 Emby Server 的地址+账号密码，不提供 Emby Connect。地址不可达、证书错误、用户名或密码错误、所选线路失败时不得进入片库。会话失效回到登录页并说明需重新登录。

验收：

- 冷启动未登录时首先看到影院风格登录页，而不是空白或系统设置风格表单堆叠
- 从登录页能添加服务器、添加线路并提交账号密码
- 错密、不可达或证书错误时仍停在登录页且能读到失败原因
- 已保存项可再选中连接，不必重填该线路地址

### R3 多服务器

行为：使用者可在登录页添加多台 Emby 服务器。登录之后，浏览界面必须一直能看见当前服务器名称，并从此处切换已保存服务器或线路、退出登录。不得把切换藏在登录页、不得只在溢出的侧栏菜单里。凭据只保存在本机；系统钥匙串或等价存储可用时写入其中。退出后须重新认证才能看到片库。

适用与失败边界：每台服务器的身份以该 Emby 的 ServerId 为准，避免把同一台机器的两条线路存成两台无关服务器（线路见 R4）。切换服务器即切换当前连接目标并刷新首页。不得绕过该服务器对该用户的片库范围与家长控制。当前「已连接 xxx」纯文案、或只在 AppBar 溢出菜单里才有切换，视为未满足。

验收：

- 能保存至少两台不同服务器
- 登录后主界面不进登录页也能看到当前服务器名并完成切换，切完后首页是目标服务器的片
- 退出后必须重新认证才能看到片库

### R4 多线路

行为：每一台已保存服务器下可添加多条线路。一条线路是访问该服务器的一个 HTTP/HTTPS 地址（例如局域网与公网）。登录时先选服务器，再选要使用的线路，然后连接。可继续为该服务器追加线路，可删除多余线路。至少保留一条线路才能用该服务器连接。

适用与失败边界：线路从属于某一服务器条目，不是又一台独立服务器。登录使用使用者当前选中的那一条线路，不在失败时自动改连其它线路。当前选中线路不可达或证书错误时停在登录页并指出是该线路失败。局域网 HTTP 可用。

验收：

- 能为同一服务器保存不少于两条不同地址的线路，并在登录页切换后分别尝试连接
- 选中线路 A 失败时不会悄悄改用线路 B 进入片库
- 删除一条线路后，其余线路仍可被选中连接

### R5 线路级 HTTP User-Agent

行为：每条线路可设置自定义 HTTP User-Agent。该线路上的连接探测、登录、片库、封面与播放拉流都使用这个 User-Agent。留空则使用本应用的默认桌面 User-Agent。自定义 UA 不改变界面上的产品名，也不把发给 Emby 的 Client 标识改成官方客户端名称。

适用与失败边界：UA 只作用于 HTTP(S) 请求头 User-Agent，包括播放器拉流。空字符串或仅空白视为未设置，回退默认。错误的 UA 仍发出请求；若服务器因此拒绝，按连接或播放失败显示原因，不得假装成功。

验收：

- 为某线路填写 UA 并连接成功后，对该线路的 API 与拉流请求带有该 User-Agent
- 清空该线路 UA 后再连接，请求使用默认 User-Agent 而不是上次自定义值
- 界面仍显示「灯川 Rillight」，不出现把产品名改成自定义 UA 的结果

### R6 浏览与播放同一套语言且能力不砍

行为：首页仍能到达继续观看、即将播放（剧集下一集）、最近添加的电影与剧集；可进电影库与剧集库海报墙与详情；可按名搜索。播放器窗口内控件可自动隐藏，空格/左右/F/Esc 仍可用；播放窗口与浏览窗口的关系见 R8。直连优先、进度回写、文本字幕等既有影视行为继续成立，本需求只改这些面的外观与信息结构，不取消这些能力。

适用与失败边界：首页某一行无内容则隐藏或空态，不得用音乐、相册填补。搜索空输入不发起请求；接口失败不得显示成「没有结果」。播放失败、断网须可见。合集/Box Set、直播、音乐不是本需求新增范围。`docs/requirements/2026-09-11-emby-desktop-player.md` 中的播放与进度验收仍适用，不以本界面重做为由免除。

验收：

- 重做后的首页能找到续看、即将播放、最近电影、最近剧集四类内容（无数据的行除外）
- 能从海报进入详情并开始或恢复播放
- 播放层为几乎全画面的暗色控件，闲时隐藏，移动鼠标或键鼠操作后可再出现
- 空格暂停、F 全屏、Esc 退出全屏且留在播放器窗口内

### R9 登录后分栏：更多与左右翻页

行为：登录后的首页、详情（以及从「更多」进入的列表页）按观影分栏组织，而不是把海报堆成难扫的杂乱网格或截断一排。每一条有内容的分栏包含：左侧栏目标题、右侧「更多」（当该栏在服务器上还有未在本行展示完的条目，或该栏本身是可进入的完整列表时必须出现）、中间横向海报轨。桌面必须提供可见的左、右翻页控件（悬停行上出现亦可，但不得完全没有），用鼠标点击即可把海报移出当前视野；同时支持在该行上滚轮/触控板横向滑动。翻页不得带动整页上下乱跳。

首页至少这些分栏（无数据则整栏隐藏，见 R6）：继续观看、即将播放、最近添加的电影、最近添加的剧集。点「更多」进入该栏的完整海报墙（例如全部续看、全部最近电影），视觉语言与首页一致。

详情页上方是一张主视觉（宽背景或大海报）+ 片名 + 主要操作（播放/继续、已看），简介与年份时长等次要信息，不得用表单标签把一页塞满。其下用同样的分栏：剧集为「季」选择与「集」横向分栏（集过多时左右翻并提供更多/看全集）；电影或剧集在服务器返回相似条目时增加「更多类似」分栏，空则隐藏。点海报进入对应详情或直接播放的规则与现有能力一致。

适用与失败边界：本条针对键鼠桌面。仅内部 `ListView` 横向、用户看不出可翻、没有箭头、没有「更多」，视为未满足。不得为塞下条目而缩小到无法点的海报，也不得改回十英尺超大磁贴。片库总览是「更多」或主题的落地页，见 R10、R11。不要求直播、音乐、相册、演职员墙作为必做分栏。

验收：

- 首页每一条可见分栏标题旁有「更多」；点「更多」进入该主题的完整列表，而不是停在被截断的一行
- 当该行海报超出一屏时，用鼠标点左/右控件能看到原先视野外的海报，无需猜测去拖空白处
- 详情页能一眼找到播放，分集或类似内容以分栏呈现，同样能左右翻；没有类似或没有下一集时不出现空壳分栏
- 重做后的登录后界面不得再被合理视为「默认 Material 后台 + 侧栏标签堆砌」

### R10 登录后导航：不用无用左侧栏

行为：登录后主框架以首页分栏为中心，辅以搜索与当前服务器入口（R3）。电影库、剧集库从首页对应分栏的「更多」或顶栏里一个短的片库选择进入，不在左侧用 NavigationRail/长列表列出每一个库。左侧长栏在库很多时既占位又溢出自相矛盾，本需求将其视为无用并禁止作为主导航。

适用与失败边界：允许极窄的首页/返回示意，不允许把每个 Views 项做成永久侧栏目的地。音乐、直播、相册仍不得进主导航（R7）。搜索必须从登录后任意浏览页一步到达。

验收：

- 登录后主视图是首页分栏，而不是先看到一排库名侧栏
- 片库数量多到无法在一屏侧栏显示时，界面仍可用，不会出现侧栏撑破窗口
- 能从首页或顶栏进入某个电影库/剧集库完整列表

### R11 主题与更多页支持排序

行为：点首页「更多」、点某个电影/剧集库或主题进入的完整海报墙，必须提供排序。至少支持：名称、添加日期、首映/发行日期。服务器还返回评分或社区评分时，增加按评分。默认添加日期新到旧，或名称；使用者改排序后列表立刻按新顺序重排。排序控件放在该页标题附近，一眼能找到。

适用与失败边界：排序作用于当前列表，不要求改 Emby 服务器上的库设置。首页横向分栏本身不要求排序控件。搜索结果可按相关度，不强制与主题页同一套排序。无数据时不出现空的排序条。当前点进主题只有固定 SortName、不能改序，视为未满足。

验收：

- 打开「最近添加的电影」更多页或某个电影库，能把排序从名称改到添加日期（或反过来），海报顺序随之变化
- 排序入口在该页可见，不必返回登录或进系统设置
- 改序失败时显示原因，不得假装已经按新序排好

### R8 播放器独立窗口

行为：视频播放器与浏览应用是两个独立窗口。从详情或首页打开播放时，弹出（或激活）播放器窗口，浏览窗口保持打开。关闭、退出全屏或结束播放只关闭或收起播放器窗口，不得退出整个应用、不得把浏览窗口一起关掉。

适用与失败边界：本条覆盖 Windows、macOS 与 Linux 桌面。全屏只作用于播放器窗口。Esc 在全屏时退出全屏并留在播放器窗口；已在窗口模式时关闭播放器，回到（仍存在的）浏览窗口。不要求同时播放多路视频。当前把播放嵌在同一应用窗口、关掉播放即退出进程，视为错误，不是可接受实现。

验收：

- 开始播放后，任务栏或窗口列表中浏览窗口与播放器窗口可区分，浏览窗口未被替换掉
- 关闭播放器窗口后，浏览窗口仍在，可继续点海报或搜索
- 关闭播放器窗口不会结束应用进程；无需重新启动即可再打开另一部影片

## 不做事项

### R7 排除项

行为：本需求不交付：把官方 Emby Web 页套进壳当作新界面；为客厅电视或遥控十英尺导航验收；跟随系统浅色主题作为通过条件；直播电视、音乐、相册作为登录后主导航；把每个片库做成永久左侧长栏；把多线路做成播放器内部的片源 CDN 切换；用自定义 UA 冒充官方客户端名称写在界面上。

适用与失败边界：与 R1–R6、R8–R11 分界。既有影视能力见 `docs/requirements/2026-09-11-emby-desktop-player.md`。关闭播放器不得被实现成退出应用。

验收：

- 主界面与播放器不是嵌入的官方 Emby Web 页
- 登录页没有「线路自动抢播/CDN 片源」作为主操作，只有服务器访问地址列表
- 验收不以系统浅色主题或电视遥控通过本需求
