# 需求：灯川 Rillight

日期：2026-09-11

## 一屏摘要

- 目标：名为「灯川 Rillight」的独立桌面客户端，在 Windows、macOS 与 Linux 上连接已有 Emby 服务器，把电影与剧集找着、播顺、进度同步（R1）
- 使用者：自建 Emby、用键盘鼠标看片的桌面用户（R1）
- 范围：登录与切服务器；首页续看/即将播放/最近添加；影视库浏览与详情；搜索；直连优先播放；文本字幕与音轨；进度与看过状态；窗口内或全屏控制（R2–R9）
- 关键行为：三平台同一套影视能力；能直连则不转码；文本字幕客户端渲染，ASS/PGS 走服务器烧录；失败可见。假设：简体中文 UI；地址+用户名密码；可保存切换服务器；局域网 HTTP 可用；下一集可自动播放且可取消（R1、R2、R6–R10）
- 成功标准：三平台都能登录并看到自己的影视库；续看能接着播；常见片源直连且进度回写到 Emby；切换字幕/音轨生效（R1–R8）
- 不做事项：不做 Server；直播/音乐/相册/离线/一起看/投屏；Jellyfin/Plex；套官方 Web 壳；DV/Atmos 与客户端 ASS/PGS 不当验收；客厅、手机非本需求验收（R11）

## 完整需求

### R1 灯川 Rillight 跨平台桌面影视客户端

行为：交付独立桌面应用「灯川 Rillight」。使用者是已经拥有自建 Emby 服务器、用键盘和鼠标看片的人。应用在 Windows、macOS 与 Linux 桌面上提供同一套能力，只服务于该 Emby 账号可见的电影与剧集：发现、打开、播放，并把进度写回服务器。默认界面为简体中文。界面与安装包展示的产品名为「灯川 Rillight」。

适用与失败边界：本需求验收平台为 Windows、macOS 与 Linux 桌面（键盘鼠标、图形界面）。某一桌面平台不能走完主路径则本需求不通过。客厅遥控、手机与平板不是本需求的验收对象。本应用不替代 Emby Server。

验收：

- 在 Windows、macOS 与 Linux 上均可启动应用并走完连接、浏览、播放主路径
- 应用内可见产品名为「灯川 Rillight」
- 不以客厅电视系统或手机、平板通过本需求
- 不以仅在其中一个桌面系统上通过，视为本需求完成

### R2 连接已有 Emby 服务器

行为：使用者输入服务器地址（http 或 https）、用户名和密码登录。成功后以该 Emby 用户身份访问其可见片库。可保存多个服务器连接并切换。凭据只保存在本机；系统钥匙串或等价系统凭据存储可用时写入其中。可退出登录。不把 Emby Connect 作为登录方式。

适用与失败边界：只连接既有 Emby Server。局域网 HTTP 可用。地址不可达、证书错误、用户名或密码错误时不得进入片库，必须显示原因。不得绕过服务器对该用户的片库范围与家长控制。会话失效时回到连接界面并说明需重新登录。

验收：

- 正确地址与账号可进入该用户的影视片库
- 错误密码或不可达地址停留在连接界面，并显示失败原因
- 退出登录后必须重新认证才能看到片库
- 已保存的服务器可再选中连接，不必重填地址

### R3 首页续看与发现

行为：登录后的首页至少包含：继续观看、即将播放（剧集下一集）、最近添加的电影、最近添加的剧集。条目显示海报与标题；继续观看显示已看进度。点击条目进入详情；继续观看可直接从近进度恢复播放。

适用与失败边界：行内只出现电影与剧集。某一行没有内容时隐藏该行或显示为空，不得用音乐、相册或其它类型填补。某一行加载失败时首页仍可打开，并说明该行不可用。合集、Box Set 不是本行的必做来源。

验收：

- 存在未看完的影视时，「继续观看」出现且能看出进度
- 从继续观看进入时从近进度恢复，而不是默认从头
- 没有可播下一集时不出现虚假的即将播放条目
- 最近添加来自该用户可见的电影或剧集，不含音乐或相册

### R4 电影与剧集浏览及详情

行为：可打开该用户可见的电影库与剧集库，以海报墙浏览。详情显示标题、年份、简介、时长或集数。电影可开始或恢复播放。剧集可按季列出各集并播放其中一集。可把条目标记为已看或未看。

适用与失败边界：只展示电影库、剧集库及其中的视频条目。直播电视、音乐、相册库不出现在本浏览中。无权限、已删除或失效条目打开时说明不可用，界面不崩溃。合集与 Box Set 浏览不是本需求必做项。

验收：

- 该用户在 Emby 中可见的电影库、剧集库能在应用中打开，并看到海报与标题
- 电影详情可以开始或恢复播放
- 剧集详情能进入某一季的某一集并播放
- 标记已看后，回到首页或刷新，该条目按服务器状态从继续观看中消失或更新

### R5 搜索影视

行为：提供按名称搜索，查找该用户可见的电影与剧集（若服务器返回季或集，结果可进入对应详情）。

适用与失败边界：不把音乐、相册或人物百科作为必做搜索类型。空查询不发起搜索。服务器搜索失败时显示失败，不得显示成「没有结果」的成功态。

验收：

- 输入片库中已有的影片标题，结果中出现该电影或剧集
- 点击结果进入对应详情
- 搜索接口失败时有可见错误；空输入不会把全部片库当作搜索结果

### R6 直连优先播放

行为：开始播放前，按客户端真实能力向服务器声明设备能力。桌面能解的常见片源必须 Direct Play：至少包括 H.264/H.265 视频、AAC/AC3 音频、MP4/MKV 容器，以及服务器按直连给出的 HLS。不能直连时才请求转码或直转。默认自动选择；处于转码时，使用者能看出当前不是直连，并可改质量档后继续播。杜比视界、Atmos/TrueHD 直通不是本需求验收项。

适用与失败边界：可直连时不得无故转码。能力申报必须与客户端实际能播放的格式一致，不得虚报后无法出画。无流、转码失败或网络中断时必须可见原因并可停止。不得把官方 Web 客户端页面当作播放器。

验收：

- 常见 H.264/H.265 + MP4/MKV、音频为 AAC/AC3、且本机解得开的影片，播放会话为 Direct Play（或服务器等价的非转码），而不是 Transcode
- 客户端解不开的编码在转码后能出画出声，或明确失败原因
- 可直连片源的正常播放不以转码会话为常态
- 转码时界面能区分直连与转码，切换质量档后仍能播放

### R7 进度与观看状态

行为：开始播放时向服务器报告 Playing；播放中约每 10 秒，以及暂停、恢复、跳转时报告进度；停止或退出播放时报告 Stopped。已有足够进度的条目再次打开时，提示继续或从头。剧集结束后可自动播放下一集，并给出可取消的倒计时。进度与已看状态以服务器为准。

适用与失败边界：对同一次播放，Stopped 之后不得再发送进度。进度上报失败不得打断仍在进行的本地画面，但须让使用者察觉同步失败。过短进度不进入继续观看。不实现多端一起看（SyncPlay）。

验收：

- 播放数分钟后，在 Emby 用户数据或官方客户端中能看到接近的进度
- 停止后再次打开该条目会出现继续观看选择；选择继续则从近位置起播
- 暂停或跳转后的进度与操作一致；停止后进度不再往后写
- 剧集结束出现下一集倒计时；取消后不会自动开播

### R8 字幕与音轨

行为：播放中可选择服务器提供的音轨与字幕。SRT、VTT 等文本字幕由客户端渲染并支持开关与切换。客户端不能渲染的 ASS/SSA、PGS 等，改为请求服务器烧录或转码后显示，或明确该格式无法在直连下渲染并给出转码选项。选择后在当前播放立即生效，或在一次可感知的重开流后生效。

适用与失败边界：没有字幕或只有一条音轨时，选择器只列出实际存在的项。烧录或转码失败时，保持无字幕或原音轨播放并说明原因。客户端原生渲染 ASS/PGS，以及杜比视界字幕特效，不是本需求验收项。

验收：

- 有多音轨时可切换，切换后听到对应音轨
- 有 SRT/VTT 时可打开、关闭或切换，画面出现对应文本
- 仅有 ASS/PGS 时，选择后通过转码或烧录看到字幕，或提示直连无法渲染并提供转码
- 无字幕的条目不出现虚假字幕轨

### R9 桌面播放控制

行为：播放发生在同一桌面窗口内，可窗口内播放或全屏。提供播放/暂停、跳转、音量、全屏。键盘：空格播放或暂停，左右跳转，F 全屏，Esc 退出全屏（已在窗口内则停止或回到详情，不退出应用）。可用鼠标点击或拖动进度条。控制条可自动隐藏以免挡画面，移动鼠标后重新出现。

适用与失败边界：不以遥控器或十英尺导航为验收。全屏后键盘与鼠标仍可用。上述控制在 Windows、macOS 与 Linux 上均须可用。

验收：

- 空格键切换播放与暂停
- 点击或拖动进度条后，画面与进度跳到对应位置
- F 进入全屏；Esc 退出全屏且仍留在应用内
- 全屏时移动鼠标可再次调出控制条

### R10 失败可见

行为：连接、片库加载、封面、播放、进度同步的失败都必须有可见说明，不得空白卡死或未处理崩溃。单张封面失败使用占位，不阻止浏览其它条目。

适用与失败边界：短暂网络抖动可以重试。认证失效回到连接界面并说明会话已失效。不得把加载失败显示成「没有影片」的成功空库。

验收：

- 播放过程中断网后，播放停止或暂停并出现提示，而不是无限转圈且无文案
- 片库接口失败时显示错误，不显示为空库成功
- 单张封面失败时其它条目仍可点击打开

## 不做事项

### R11 排除项

行为：本需求不交付下列结果：实现 Emby Server；直播电视与录像；音乐播放；相册；离线下载；SyncPlay；投屏（如 Chromecast、AirPlay）；Jellyfin 或 Plex 客户端；把官方 Web 客户端套壳当作本产品；以杜比视界或 Atmos 直通、或以客户端原生 ASS/PGS 渲染作为通过条件；以客厅电视系统、手机或平板作为本需求验收平台。

适用与失败边界：与 R1–R10 的 Windows / macOS / Linux 桌面影视客户端分界。上述能力若需要，另写需求。

验收：

- 无直播电视、音乐、相册作为主导航
- 无「下载后离线观看」功能入口
- 无 Jellyfin 或 Plex 服务器类型选项
- 主界面与播放器不是嵌入的官方 Emby Web 页
- 验收记录不以电视或手机通过本需求，也不以 DV/Atmos 直通失败判定本需求失败
- 验收记录覆盖 Windows、macOS 与 Linux，不以仅单一桌面系统通过本需求
